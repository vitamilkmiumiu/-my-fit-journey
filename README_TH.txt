MY FIT JOURNEY — วิธีเผยแพร่และติดตั้งบน iPhone

ไฟล์นี้เป็น PWA ภาษาไทย รุ่นเริ่มต้น ใช้ข้อมูลใน localStorage ของ Safari บนอุปกรณ์นี้

วิธีเผยแพร่ฟรีด้วย GitHub Pages (ต้องใช้อินเทอร์เน็ตและบัญชี GitHub)
1. เปิด https://github.com ใน Safari แล้วสมัคร/เข้าสู่ระบบ
2. สร้าง repository ใหม่ ตั้งชื่อ my-fit-journey และเลือก Public
3. แตกไฟล์ ZIP นี้ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ขึ้นไปที่ root ของ repository (ไม่ใช่อัปโหลด ZIP อย่างเดียว)
4. เข้า Settings > Pages
5. ใน Build and deployment เลือก Deploy from a branch
6. เลือก branch main และ folder /(root) แล้วกด Save
7. รอ GitHub Pages เผยแพร่ แล้วเปิด URL ที่ GitHub แสดงให้ (โดยทั่วไป https://ชื่อผู้ใช้.github.io/my-fit-journey/)

วิธีติดตั้งบน iPhone
1. เปิด URL ที่เผยแพร่แล้วด้วย Safari (ไม่ใช่เบราว์เซอร์ในแอปอื่น)
2. กด Share (สี่เหลี่ยมมีลูกศรขึ้น)
3. เลือก Add to Home Screen
4. เปิด Open as Web App หากมีตัวเลือก แล้วกด Add
5. เปิดแอปจากไอคอน My Fit Journey บนหน้าจอ Home

หมายเหตุสำคัญ
- ข้อมูลบันทึกใน Safari ของเครื่องนี้ ไม่ซิงก์ข้ามอุปกรณ์ และอาจหายได้หากล้างข้อมูลเว็บไซต์/ลบข้อมูล Safari หรือถอนการติดตั้งข้อมูลเว็บ
- ใช้ปุ่ม “ดาวน์โหลดข้อมูลสำรอง (JSON)” ในหน้า ความคืบหน้า เป็นระยะ
- ถ้าแก้ไขไฟล์หลังเผยแพร่ อาจต้องปิดแล้วเปิดแอปใหม่ หรือรีเฟรชเพื่อรับเวอร์ชันล่าสุด
- แอปนี้ไม่ใช่คำแนะนำทางการแพทย์ และไม่คำนวณแคลอรี/วินิจฉัยสุขภาพ
- GitHub Pages ให้บริการ static hosting; URL ที่เผยแพร่จะเป็นเว็บไซต์สาธารณะ อย่าบันทึกข้อมูลอ่อนไหว
